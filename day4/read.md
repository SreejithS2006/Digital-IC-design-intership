---

# Introduction

Block RAM (BRAM) is a dedicated memory resource available inside FPGA devices. Unlike memories implemented using LUTs and registers, BRAM utilizes specialized memory blocks present in FPGA hardware, resulting in efficient memory implementation with reduced logic utilization.

Xilinx Vivado provides a **Block Memory Generator IP** that allows designers to create configurable RAM structures without manually coding memory arrays.

In this task, a Block Memory Generator IP was configured as a Single-Port RAM and verified through simulation and synthesis.

# Working Principle

The Block Memory Generator performs memory operations based on the supplied addresses and control signals.

## Write Operation

When Write Enable is HIGH:

```text
wr_enb = 1
```

The input data is stored at the specified write address.

```text
Memory[wr_ad] ← d_in
```

---

## Read Operation

The memory contents are accessed using the read address.

```text
d_out ← Memory[rd_add]
```

The output displays the data stored at the selected address.

# Resource Description

## Slice LUTs (Look-Up Tables)

Look-Up Tables implement combinational logic functions inside the FPGA.

* Utilized: **26 LUTs**
* Used for address decoding and memory control logic.
* Indicates efficient logic implementation.

---

## Slice Registers

Registers store sequential data.

* Utilized: **72 Registers**
* Used for memory storage and output synchronization.
* Enable stable and synchronous operation.

---

## F7 Multiplexers

F7 MUX resources are dedicated FPGA multiplexers.

* Utilized: **8 F7 MUXes**
* Used in memory read-path selection.
* Improve routing efficiency and speed.

---

## Bonded IOB (Input/Output Blocks)

Input/Output Blocks connect FPGA logic to external signals.

* Utilized: **25 IOBs**
* Used for clock, reset, address, data, and control signals.

---

## BUFGCTRL

BUFGCTRL is a global clock buffer resource.

* Utilized: **1 BUFGCTRL**
* Provides low-skew clock distribution throughout the FPGA.
