# Day 3 – Task 2: Face Detection Data Processing System Using FIFO Design and Verification

## Objective

To design and verify a data processing system consisting of a **Face Detection Module**, **FIFO Buffer**, and **Output Processing Module** using Verilog HDL and simulate its functionality using Xilinx Vivado.

---

## Introduction

In digital systems, data generated by one module often needs temporary storage before being processed by another module. A **FIFO (First-In First-Out)** buffer is commonly used for this purpose, ensuring that data exits the system in the same order in which it enters.

In this task, a complete processing chain was implemented consisting of:

1. Face Detection Module
2. FIFO Memory Buffer
3. Output Processing Module

The system accepts 8-bit input data, processes it through the face detection stage, stores the processed data in a FIFO, and finally forwards the data to the output module.

---

## System Architecture

The complete system consists of three interconnected modules:

### Module 1: Face Detection Module

The Face Detection Module receives:

* Clock Signal (`clk`)
* 8-bit Input Data (`d_in[7:0]`)

and generates:

* Processed Data (`s_out[7:0]`)

This module represents the preprocessing stage of the system.

### Module 2: FIFO Buffer

The FIFO acts as temporary storage between processing stages.

#### Inputs

* Data Input (`data_in[7:0]`)
* Write Enable (`wrenb`)
* Read Enable (`rdenb`)
* Clock (`clk`)
* Reset (`rst`)

#### Outputs

* Data Output (`data_out[7:0]`)
* Full Flag (`full`)
* Empty Flag (`empty`)

The FIFO ensures data integrity by maintaining First-In First-Out behavior.

### Module 3: Output Module

The Output Module receives data from the FIFO and introduces a **3-clock-cycle delay** before generating the final output.

#### Inputs

* Clock (`clk`)
* FIFO Output Data (`d_in[7:0]`)

#### Output

* Final Output Data (`d_out[7:0]`)

#### Working Principle

The module stores the incoming data through a series of registers. The data propagates through three sequential stages, and the final output is generated only after the third positive edge of the clock.

For example:

| Clock Edge  | Data Position             |
| ----------- | ------------------------- |
| 1st Posedge | Stage 1 Register          |
| 2nd Posedge | Stage 2 Register          |
| 3rd Posedge | Output Register (`d_out`) |

Thus, the output data appears after a latency of **3 clock cycles** from the time it is received from the FIFO.

This delay mechanism is useful for synchronization, pipelining, and timing alignment in digital processing systems.


## Working Principle

The system operates as follows:

1. Input data is applied to the Face Detection Module.
2. Processed data is sent to the FIFO buffer.
3. Write Enable allows data to be stored in FIFO memory.
4. Read Enable retrieves data from FIFO in the same order it was written.
5. Retrieved data is forwarded to the Output Module.
6. The Output Module generates the final output data stream.

Because FIFO follows the First-In First-Out principle, the output sequence preserves the order of the incoming data.
